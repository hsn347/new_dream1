أريد منك إنشاء **تصميم واجهات فقط (UI/Prototype)** لمشروع SaaS لوكيل ذكاء اصطناعي للمبيعات يعمل عبر واتساب.

**مهم جدًا:**

* لا تنفذ Backend
* لا تنفذ منطق تشغيل فعلي
* لا تربط APIs حقيقية
* لا تنشئ نظام تسجيل حسابات للمستخدم النهائي
* فقط صمم الواجهات بشكل احترافي جدًا، كأنها نموذج أولي جاهز مثل Figma لكن داخل Replit

## الأسلوب العام

أريد التصميم مستوحى بقوة من الصورة المرفقة:

* Sidebar جانبي داكن بلون أخضر/تركوازي
* محتوى رئيسي فاتح ونظيف
* بطاقات حديثة rounded
* ظلال ناعمة
* Dashboard premium
* مؤشرات دائرية
* كروت إحصائيات
* جداول أنيقة
* مظهر احترافي جدًا
* الواجهة تكون RTL ومناسبة للعربية

## مهم جدًا للجوال

عند فتح الموقع على الجوال، أريده أن يبدو **مثل تطبيق حقيقي وليس موقعًا**:

* تصميم mobile-first
* تنقل شبيه بالتطبيق
* sidebar يتحول إلى drawer أو bottom navigation حسب الأفضل
* المسافات والخطوط مناسبة للجوال
* كل صفحة تبدو كواجهة app وليست web page
* سهولة استخدام عالية بالإصبع
* شكل حديث جدًا على الهاتف

# 2) لوحة الأدمن

الأدمن لديه **صفحتان رئيسيتان فقط**:

## الصفحة الأولى: إدارة المفاتيح

هذه الصفحة خاصة بإدارة:

* مفاتيح الشات
* مفاتيح التضمين

### المطلوب فيها:

* إمكانية إضافة أكثر من مفتاح
* لكل مفتاح:

  * نوعه: chat أو embedding
  * اسم المزود
  * اسم النموذج
  * API Key
  * حالة الاتصال
  * استهلاك التوكن
  * عدد الطلبات
  * آخر تحديث
* أزرار:

  * Add Key
  * Edit
  * Disable
  * Test Connection
* عرض إحصائيات أعلى الصفحة
* Cards أو table منظمة
* عرض استهلاك التوكن لكل نموذج ولكل مفتاح
* فلترة حسب النوع أو الحالة أو المزود

## الصفحة الثانية: إدارة المستخدمين وتجهيزهم

هذه الصفحة خاصة بـ:

* إضافة المستخدمين
* تعديل المستخدمين
* تجهيز كل مستخدم

### كل مستخدم يحتاج 3 أشياء:

1. نموذج شات
2. نموذج تضمين
3. إعداد واتساب الخاص به

### المطلوب في الصفحة:

* قائمة المستخدمين
* زر Add User
* modal أو صفحة لإنشاء مستخدم
* عند إنشاء المستخدم يتم اختيار:

  * chat model
  * embedding model
  * WhatsApp provider
  * بيانات واتساب
* حالة المستخدم:

  * Active
  * Pending
  * WhatsApp connected
  * Models connected
* تصميم إداري نظيف واحترافي

# 7) المطلوب من Replit

ابنِ المشروع كـ **تصميم واجهات فقط**، بحيث:

* يبدو كمنتج SaaS حقيقي
* يكون جاهزًا للتطوير لاحقًا
* يعتمد على بيانات وهمية mock data
* لا يحتوي على منطق backend
* لا يحتوي على ربط حقيقي
* كل شيء يكون UI/UX فقط
* التصميم يكون responsive جدًا
* وعلى الجوال يكون مثل تطبيق موبايل فعلي
