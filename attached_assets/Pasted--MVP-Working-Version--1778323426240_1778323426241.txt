الآن أريد الانتقال من مرحلة التصميم فقط إلى مرحلة التشغيل الفعلي بالحد الأدنى (MVP Working Version).

أريد منك تنفيذ ربط حقيقي وفعلي للنظام مع:

* WhatsApp عبر Evolution API
* نموذج Chat حقيقي
* نموذج Embedding حقيقي

مع الحفاظ على نفس التصميم الحالي.

مهم جدًا:

* أريد تشغيل فعلي حقيقي
* واختبار اتصال حقيقي
* وليس mock data أو fake status
* يجب أن يظهر فعليًا إذا كان الاتصال ناجحًا أو فاشلًا

---

# 1) المطلوب الآن

أريد:

* ربط فعلي مع Evolution WhatsApp
* ربط فعلي مع Groq Chat Model
* ربط فعلي مع Cohere Embedding Model
* إنشاء webhook فعلي
* استقبال رسائل واتساب
* إرسال رد تلقائي بسيط
* حفظ الإعدادات من لوحة الأدمن
* اختبار اتصال حقيقي لكل خدمة

---

# 2) نماذج الشات

مزود الشات:
Groq

اسم النموذج:

```txt
openai/gpt-oss-120b
```

يجب أن يكون هناك:

* صفحة إدارة مفاتيح حقيقية
* إمكانية إضافة Chat Provider
* تخزين بيانات النموذج
* اختبار اتصال فعلي
* إظهار نجاح أو فشل الاتصال فعليًا

مثال البيانات الحالية للاختبار فقط:

```txt
Provider: Groq
Model: openai/gpt-oss-120b
API Key: [سأقوم بإدخالها من الواجهة لاحقًا]
```

---

# 3) نماذج التضمين Embeddings

المزود:
Cohere

اسم النموذج:

```txt
embed-multilingual-v3.0
```

المطلوب:

* ربط فعلي مع Cohere
* اختبار اتصال فعلي
* إظهار حالة الاتصال
* إمكانية إضافة Embedding Models من لوحة الأدمن

مثال بيانات الاختبار الحالية:

```txt
Provider: Cohere
Model: embed-multilingual-v3.0
API Key: [سأقوم بإدخالها من الواجهة لاحقًا]
```

# 5) المطلوب من النظام

## أ) إنشاء Webhook فعلي

أريد أن يقوم النظام بإنشاء webhook URL فعلي مثل:

```txt
https://YOURDOMAIN/api/webhooks/evolution/:userId
```

ويظهر داخل لوحة الأدمن أو إعداد المستخدم.

---

## ب) اختبار اتصال حقيقي

عند الضغط على:

```txt
Test Connection
```

يجب:

* إرسال request حقيقي إلى Evolution
* وإذا نجح:

  * يظهر Connected
* وإذا فشل:

  * يظهر Error مع الرسالة

أريد اختبار حقيقي وليس مجرد تغيير لون وهمي.

---

## ج) استقبال الرسائل فعليًا

أريد:

* استقبال رسائل واتساب من Evolution عبر webhook
* قراءة نص الرسالة
* إرسالها إلى نموذج الشات
* إعادة الرد إلى العميل عبر واتساب

حتى لو كان الرد بسيطًا الآن.

---

## د) إرسال الرد عبر واتساب

عند وصول رسالة:

* يتم توليد رد عبر Groq
* ثم إرساله عبر Evolution API
